# Marathon Bot

Minimal Discord bot skeleton. Connects, sets a custom status, and stays online. Used as a base or presence indicator for the Marathon community server.

## Setup

```bash
pip install -r requirements.txt
```

Set environment variables:

| Variable | Description |
|---|---|
| `DISCORD_TOKEN` | Your bot token |

## Run

```bash
python bot.py
```

## Stack

- Python
- discord.py
